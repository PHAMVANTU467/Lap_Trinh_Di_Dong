Đồ án môn Lập Trình Di Động — Ứng dụng quản lý tài chính thông minh, theo dõi thu chi hàng ngày và phân tích ngân sách cá nhân trực quan bằng biểu đồ.

---

## ✨ Tính năng chính (Features)

- 💰 **Ghi chép giao dịch nhanh:** Thêm khoản thu/chi với danh mục cụ thể (Ăn uống, Giải trí, Tiền nhà, Lương...).
- 📊 **Biểu đồ trực quan:** Thống kê thu chi theo tuần, tháng và danh mục dưới dạng biểu đồ tròn và cột.
- 🎯 **Ngân sách & Hạn mức:** Thiết lập hạn mức chi tiêu để tránh bội chi.
- 🗄️ **Lưu trữ Offline an toàn:** Cơ sở dữ liệu SQLite cục bộ, bảo mật và truy xuất dữ liệu tức thì không cần mạng.
- 🎨 **Giao diện hiện đại:** Thiết kế theo chuẩn Material Design 3, thao tác vuốt chạm mượt mà.

---

## 🛠️ Cài đặt & Khởi chạy (Getting Started)

Yêu cầu: Đã cài đặt [Flutter SDK](https://flutter.dev/docs/get-started/install).

```bash
# 1. Clone repository
git clone https://github.com/PHAMVANTU467/Lap_Trinh_Di_Dong.git
cd Lap_Trinh_Di_Dong

# 2. Cài đặt dependencies
flutter pub get

# 3. Chạy ứng dụng trên máy ảo hoặc thiết bị thật
flutter run
```
